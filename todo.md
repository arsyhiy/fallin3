# интерфейс

## главное меню игры

одна статичная картинка (нарисую черновой вариант). по горизонтали крайнего права
и вертикальной середины кнопка начать игру посылающей к первому уровню (их два)

## меню на ecs

проще говоря также правого края по середине ты имеешь три кнопки вернуться к игре,
вернуться в меню и выйти из игры и все что игрок видел через камеру заблюренно что
бы видеть только нормально меню

## hud

HUD игрока, отображаемый поверх игрового мира.

HUD состоит из:
- радара слева;
- индикатора HP над радаром;
- информации об оружии справа:
  - количество патронов в магазине;
  - количество оставшихся патронов.

Также имеется crosshair в центре экрана.

При наведении crosshair на дверь:
- появляется надпись «Открыть дверь»;
- отображается кнопка, которую необходимо нажать для взаимодействия.


# игрок

- передвигатся - ходить, присидать, прыгать.
- смотреть на окружающие пространство - камера от третьего лица.
- открывать и закрывать двери
- стрелять из охотничьго ружья и перезарижатся
- сражатся с врагами
- иметь здоровье - терять его и востанавливать стимпаками
- при потере здоровья игра заканчивается и показывает game over


# оружие

- охотничье ружьё;
- стрельба;
- боезапас;
- перезарядка;
- попадание;
- нанесение урона;
- звук выстрела;
- визуальный эффект выстрела.

# враг

- иметь маршрут по карте.
- обнаруживать игрока в пределах поля зрения.
- после обнаружения игрока строить маршрут до него.
- двигаться по построенному маршруту.
- атаковать игрока.
- иметь здоровье.
- при смерти должен становится простым ragdoll

# звук

## звуки окружающей среды
- звуки помещения;
- звуки окружающего мира.

## звуки действий
- выстрел;
- перезарядка;
- открытие двери;
- закрытие двери;
- атаки врага;
- получение урона;
- смерть.


# завершение игры

- смерть игрока приводит к перезапуску уровня;
- прохождение второго уровня приводит к завершению демки.


# взаимодействие

- игрок может взаимодействовать с окружающей средой;
- игрок может открывать двери;
- игрок может закрывать двери;
- взаимодействие происходит через crosshair.


# уровни

- два уровня;
- возможность перейти с первого уровня на второй;
- возможность завершить второй уровень.


# система урона

- игрок может наносить урон врагу;
- враг может наносить урон игроку;
- урон уменьшает HP;
- при достижении 0 HP персонаж умирает.
